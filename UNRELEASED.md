# Unreleased changes

Collected here until the next release, then used as the GitHub / Modrinth notes.

- Double-click the installer: a window shows the progress, finds Java 8 on your PC (also the Minecraft launcher's
  own), asks you to accept Mojang's EULA and starts the server in its own window. Before, a double-click only
  flashed a console window.
- Start script: with none in the folder it makes `start-server.bat`; double-click that from then on. Your own
  `start.bat` (or `run.sh`, ...) is never replaced: the window offers to update it, and then changes only the jar
  name after saving a backup (`start.bat.backup`).
